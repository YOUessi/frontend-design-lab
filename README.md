# Frontend Design Lab

A frontend UI design portfolio by You Tang, built with React, Vite and Tailwind CSS.

这是一个前端 UI 设计作品集仓库，用于集中展示餐厅网站、咖啡馆网站、AI 产品界面、落地页和后台系统设计。

## Deploy to GitHub Pages

This project includes a GitHub Actions workflow.

After uploading the files to GitHub:

1. Open repository **Settings**
2. Go to **Pages**
3. Set **Build and deployment → Source** to **GitHub Actions**
4. Push or upload files again if needed
5. Wait for the workflow to finish

The website will be available at:

```text
https://YOuess.github.io/frontend-design-lab/
```

If your GitHub username is not `YOuess`, update the `homepage` in `package.json` and the text above.
